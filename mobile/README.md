# Mobile — External Dossier Player

Isolated foundation for the external mobile player.

The existing Studio Dossiers tool remains the single place to create, edit, publish, and manage dossier content. This directory is reserved for the external mobile reading experience and must not duplicate dossier authoring or management.

The player will consume published dossiers enabled for mobile publication. It will use the existing dossier and page records rather than copying their media or content.

Current stage: publication opt-in and stable mobile identifier are being added to the existing dossier publication form. The external player itself is not implemented yet.
