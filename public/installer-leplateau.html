LE PLATEAU IA

Installez la version française comme une application distincte d’AISTAGE.ONE, sans changer votre installation actuelle.

Cette page demande l’installation de LE PLATEAU IA, et non celle d’AISTAGE.ONE.

Dans Microsoft Edge, ouvrez le menu … en haut à droite, puis Plus d’outils → Applications → Installer ce site en tant qu’application.

Vérifiez que le nom est LE PLATEAU IA et confirmez l’installation.

Pour créer l’icône sur le bureau : ouvrez edge://apps, choisissez LE PLATEAU IA → Détails → Créer un raccourci sur le bureau.
